The FWTXRP server uses a dedicated voice channel system to keep roleplay organized and immersive. Instead of a single shared channel, players are sorted into specific radio channels based on their role, department, or active scene — keeping law enforcement traffic separate from civilians, fire crews, and staff operations.

## Command Syntax

Use the `/vc` command to place yourself — or another user — into a voice channel.

```
/vc [abbreviation]
/vc [username] <abbreviation>
```

- **`/vc [abbreviation]`** — Joins you to the specified voice channel. If you are already in a voice channel, this drags you into the new one.
- **`/vc [username] <abbreviation>`** — Moves another player into the specified voice channel.

<Note>
  **Scene 1** (`s1`) is the default main voice channel. When in doubt, `/vc s1` places you in the primary scene channel.
</Note>
