## Voice Channel Drag System

Voice channel abbreviations allow players to run the `;vc` command to move themselves into a specific voice channel. If a player is already in a voice channel, running `;vc <abbreviation>` will drag them directly into the target channel.

To move another user into a voice channel, use:

```
;vc [usernames] <abbreviation>
```

To join a voice channel of people near your character's location, use:

```
;vc nearby
```
