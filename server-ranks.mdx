Your rank in FWTXRP determines which vehicles you can drive and which weapons you can carry. Ranks are tied to your Discord status, community activity, and whitelist approvals — some unlocks require you to hold **multiple ranks simultaneously**. Read every requirement carefully before using a vehicle or weapon.

<Note>
  Rank requirements **stack**. If a vehicle or weapon lists more than one rank, you must hold **all** of those ranks at the same time to use it. Holding one without the other does not grant access.
</Note>

## Rank Tiers

<Steps>
  <Step title="Community Member">
    The base rank available to every member who joins the FWTXRP Discord. No additional requirements — you receive this rank automatically when you become part of the community.

    **Vehicles available:**

    | Vehicle | Restriction |
    |---|---|
    | 4-Wheeler & ATV | High Rock area only |
    | Trackor | Farms only |
    | Lawn Mower | On grass only |
    | News Reporter Van | Do not interfere with active scenes |

    **Weapons available:**

    | Weapon | Notes |
    |---|---|
    | TEC-9 | Must have priority; self-defense allowed |
    | LMT L129A1 | Must have priority; self-defense allowed |
    | Skorpian | Must have priority; self-defense allowed |
    | Desert Eagle | No priority needed |
    | Colt M1911 | No priority needed |
    | Berreta M9 | No priority needed |
    | Knife | No priority needed to kill with melee |
    | Bat | No priority needed to kill with melee |
    | Hammar | No priority needed to kill with melee |
  </Step>

  <Step title="Server Booster x1">
    Awarded when you actively boost the FWTXRP Discord server with **one boost**. Boosting directly supports the community and unlocks a range of civilian vehicles and additional weapons.

    **Vehicles unlocked:**

    | Vehicle |
    |---|
    | Navara Horizon |
    | Chevlon Corbeta RZR |
    | Overland Apache SFP 2020 |
    | Falcon Advance 450 2020 |
    | Stuttgart Vierturig 2021 |
    | Celestial Type-5 |

    **Weapons unlocked:**

    | Weapon | Additional Requirements |
    |---|---|
    | Kriss Vector | Server Booster x1 only |
    | Colt Python | Server Booster x1 only |
    | M14 | Also requires **Active Roleplayer** |
    | AK-47 | Also requires **Whitelisted Member** |
  </Step>

  <Step title="Server Booster x2">
    Awarded when you boost the FWTXRP Discord server with **two boosts**. This tier builds on Booster x1 and unlocks a further set of exclusive vehicles.

    **Vehicles unlocked:**

    | Vehicle | Restriction |
    |---|---|
    | Chevlon Corbeta X08 | No restrictions |
    | Chevlon Corbeta 1M Edition 2014 | Cannot be driven off-road |
    | Bullhorn Determinator SFP Blackjack WB 2020 | No restrictions |

    **Weapons unlocked:**

    | Weapon | Additional Requirements |
    |---|---|
    | PPSH 41 | Also requires **Active Roleplayer** |
  </Step>

  <Step title="Level 1 Roleplayer">
    Earned by actively participating in roleplay and reaching Level 1 community standing. This rank unlocks additional vehicles **only when combined with Server Booster x1**.

    **Vehicles unlocked (requires Server Booster x1):**

    | Vehicle |
    |---|
    | Falcon Advance 350 Royal Ranch 2020 |
    | Falcon Advance 450 Royal Ranch 2020 |
  </Step>

  <Step title="Level 2 Roleplayer">
    Earned by continuing active participation and reaching Level 2 community standing. This rank unlocks an additional vehicle **only when combined with both Server Booster x1 and Active Roleplayer**.

    **Vehicles unlocked (requires Server Booster x1 + Active Roleplayer):**

    | Vehicle |
    |---|
    | Averon Anodic 2024 |
  </Step>

  <Step title="Active Roleplayer">
    A designation granted to members who consistently show up and contribute quality roleplay to the server. This rank unlocks vehicles and weapons in combination with booster tiers.

    **Vehicles unlocked (requires Server Booster x1 or x2):**

    | Vehicle | Additional Requirements |
    |---|---|
    | Bullhorn Determinator SFP Fury 2022 | Also requires **Server Booster x1** |
    | Celestial Truckatron 2024 (Cybertruck) | Also requires **Server Booster x1** |

    **Weapons unlocked:**

    | Weapon | Additional Requirements |
    |---|---|
    | M14 | Also requires **Server Booster x1** |
    | PPSH 41 | Also requires **Server Booster x2** |
    | Drone | Also requires **Server Booster x1** + **Whitelisted Member**; do not interfere with active scenes |
  </Step>

  <Step title="Whitelisted Member">
    Granted after you are approved for a whitelisted department such as the Fort Worth Police Department (FWPD) or the Fire Department (FD). This is the highest civilian-accessible rank tier and unlocks the most advanced vehicles and weapons.

    **Vehicles unlocked:**

    | Vehicle |
    |---|
    | Averon LM R 2020 |
    | Averon LM 2020 |
    | Celestial Type-6 2022 |
    | Celestial Type-7 2022 |
    | Takeo Experience 2021 |

    **Weapons unlocked:**

    | Weapon | Additional Requirements |
    |---|---|
    | Remington 870 | Whitelisted Member only |
    | AK-47 | Also requires **Server Booster x1** |
    | Drone | Also requires **Server Booster x1** + **Active Roleplayer**; do not interfere with active scenes |
  </Step>
</Steps>

| Falcon Advance 450 Royal Ranch 2020 | Level 1 Roleplayer + Server Booster x1 |
| Averon Anodic 2024 | Level 2 Roleplayer + Server Booster x1 + Active Roleplayer |
| Bullhorn Determinator SFP Fury 2022 | Active Roleplayer + Server Booster x1 |
| Celestial Truckatron 2024 | Active Roleplayer + Server Booster x1 |
